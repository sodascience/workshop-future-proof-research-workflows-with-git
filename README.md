# Future-proof Your Research Workflow with Git

Introductory workshop about using Git in research for [ODISSEI Early Career Day, 4 November 2026](https://odissei-data.nl/event/odissei-early-career-day-2026/).

Learn how to use Git to track changes to project files so you can recover earlier versions, collaborate with others, and make your research more reproducible.
